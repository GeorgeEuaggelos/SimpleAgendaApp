# 📅 SimpleAgendaApp - Schedly

Το **Schedly** είναι μια αυτόνομη **Android εφαρμογή** σχεδιασμένη για τη διαχείριση ραντεβού, την παρακολούθηση τοποθεσίας του χρήστη και την τοπική αποθήκευση δεδομένων.  
Αναπτύχθηκε εξ ολοκλήρου με **Android Native** τεχνολογίες, αξιοποιώντας **Java** και **SQLite**, με έμφαση στην **ευκολία χρήσης**, τη **λειτουργικότητα** και την **ασφάλεια**.

---

## 🧩 1. Εισαγωγή

Η εφαρμογή επιτρέπει στους χρήστες:
- Να **προσθέτουν, επεξεργάζονται και διαγράφουν ραντεβού**.
- Να βλέπουν **πρόγνωση καιρού** για 6 ημέρες με χρήση του **OpenWeather API**.
- Να **παρακολουθούν την τοποθεσία** τους σε πραγματικό χρόνο μέσω GPS.
- Να συνδέονται με **ασφαλή ταυτοποίηση**, περιλαμβάνοντας **βιομετρικό έλεγχο** (δακτυλικό αποτύπωμα).

---

## ⚙️ 2. Τεχνολογικό Stack

| Τεχνολογία | Περιγραφή |
|-------------|------------|
| **Android Native** | Ανάπτυξη για Android με Java |
| **Java** | Γλώσσα προγραμματισμού |
| **SQLite** | Ενσωματωμένη τοπική βάση δεδομένων |
| **Gradle** | Σύστημα αυτόματης δόμησης έργου |
| **OpenWeather API** | Παροχή δεδομένων καιρού |
| **Android Biometric API** | Υλοποίηση ελέγχου δακτυλικού αποτυπώματος |

---

## 🧱 3. Κύρια Components

### Activities
- **MainActivity.java** – Κεντρική διεπαφή και λίστα ραντεβού.  
- **LoginActivity.java** – Είσοδος χρηστών με βασικό authentication.  
- **RegistrationActivity.java** – Εγγραφή νέων χρηστών.

### Data Management
- **DBHandler.java** – Επικοινωνία με SQLite DB (CRUD λειτουργίες).  
- **Appointment.java** – Model class για αντικείμενα ραντεβού.  
- **AppointmentAdapter.java** – Custom RecyclerView adapter.

### Location Services
- **GPSTracker.java** – Ανάκτηση γεωγραφικών συντεταγμένων του χρήστη.

---

## 🌦️ 4. Βασικές Λειτουργίες

- **Διαχείριση Χρηστών**: Εγγραφή και σύνδεση μέσω απλής φόρμας.  
- **Ραντεβού (Appointments)**: Δημιουργία, επεξεργασία και διαγραφή τοπικά.  
- **Πρόγνωση Καιρού**: Εμφάνιση δεδομένων για 6 ημέρες με OpenWeather API.  
- **Εντοπισμός Τοποθεσίας**: Ανάκτηση θέσης χρήστη μέσω GPS/Geolocation API.  
- **Ασφαλής Πρόσβαση**: Βιομετρική ταυτοποίηση (Fingerprint Authentication).  
- **SQLite CRUD**: Τοπική αποθήκευση χωρίς ανάγκη δικτύου.

---

## 🧩 5. Αρχιτεκτονική Σχεδίασης

Η SimpleAgendaApp ακολουθεί **Activity-based αρχιτεκτονική** της πλατφόρμας Android:
- **Activity Lifecycle** για διαχείριση διεπαφών.
- **SQLite** για τοπική αποθήκευση.
- **RecyclerView** για εμφάνιση λιστών.
- **Location Services** με runtime permissions.

---

## 🔒 6. Θέματα Ασφάλειας

- **Authentication**: Ελεγχόμενη είσοδος/εγγραφή χρηστών.  
- **Τοπική αποθήκευση**: Τα δεδομένα μένουν αποκλειστικά στη συσκευή.  
- **Runtime Permissions**: Έλεγχος πρόσβασης GPS σε πραγματικό χρόνο.  
- **Βιομετρική Ταυτοποίηση**: Γρήγορη και ασφαλής είσοδος.  
- **Ασφάλεια API**: Όλη η επικοινωνία με OpenWeather γίνεται μέσω HTTPS.

## 🎨 7. Διεπαφή Χρήστη (UI)

- **Custom Adapters** για προσωποποιημένες λίστες.  
- **Form-based Interfaces** για καταχώρηση στοιχείων.  
- **List-based Views** (RecyclerView) για εμφάνιση ραντεβού.  
- **Κάρτες Καιρού** με εικονίδια και θερμοκρασία ανά ημέρα.  
- **Διαδραστικοί Χάρτες** για οπτικοποίηση τοποθεσίας.  
- **UI Βιομετρικού Ελέγχου** για ενεργοποίηση/απενεργοποίηση fingerprint login.

## 🛠️ 8. Οδηγίες Εγκατάστασης & Build

### Προαπαιτούμενα
- **Android Studio Flamingo ή νεότερο**
- **JDK 17** (συμπεριλαμβάνεται στο Android Studio)
- **Android SDK** (όπως ορίζεται στο `compileSdk` του project)
- **Internet connection** (για ανάκτηση καιρικών δεδομένων)

### Βήματα Εγκατάστασης
1. Κάνε clone το repository:
   ```bash
   git clone https://github.com/USERNAME/SimpleAgendaApp.git
   cd SimpleAgendaApp
2. Άνοιξε το project στο Android Studio.
3. Περίμενε το Gradle Sync να ολοκληρωθεί.
4. Ενημέρωσε το local.properties: apiKey = το_δικό_σου_OpenWeather_key
5. Επίλεξε Run ▶ ή Build → Build APK(s) για να κάνεις compile.

---

## 📱 9. Τρόπος Χρήσης

1. Δημιούργησε λογαριασμό ή κάνε login.
2. Πρόσθεσε νέα ραντεβού (τίτλος, ώρα, τοποθεσία, σημείωση).
3. Δες τον καιρό για τις επόμενες 6 ημέρες.
4. Ενεργοποίησε τον βιομετρικό έλεγχο για γρήγορη είσοδο.
5. Δες/τροποποίησε/διέγραψε ραντεβού μέσω του RecyclerView.

---

## 🧠 10. Συμπεράσματα

Η SimpleAgendaApp είναι ένα αξιόπιστο παράδειγμα native Android εφαρμογής για διαχείριση ραντεβού και καθημερινών δραστηριοτήτων.
Συνδυάζει offline-first αποθήκευση, εντοπισμό τοποθεσίας, πρόγνωση καιρού και ασφαλή πρόσβαση μέσω βιομετρίας.
Αποτελεί μια ελαφριά, αποδοτική και ασφαλή λύση για την οργάνωση της καθημερινότητας.
